\section{Hierarchical Retiming}
\sepframe[image={\includegraphics[width=3.5cm]{nyu-brand/nyu-torch.jpg}}]

\begin{frame}{Overview}


    \begin{itemize}
        \item Retiming traditionally operates on an entire circuit, monolithically
        \item Here, we describe a hierarchical approach to retiming
        \item Within the context of a module that invokes a submodule, we split the \textit{original} retiming problem of the module into an \textit{interior} and \textit{exterior}
        \begin{itemize}
            \item Exterior problem is constructed using the results of the interior problem
            \item Interior retimes subgraph for submodule, with super-source and super-sink nodes
            \item Exterior retimes parents module, replace submodule with a \textit{contracted graph}
        \end{itemize}
    \end{itemize}
