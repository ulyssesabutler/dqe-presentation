\section{Hierarchical Retiming}
\sepframe[image={\includegraphics[width=3.5cm]{nyu-brand/nyu-torch.jpg}}]

\begin{frame}{Overview}


    \begin{itemize}
        \item Retiming traditionally operates on an entire circuit, monolithically
        \item Here, we describe a hierarchical approach to retiming
        \item Within the context of a module that invokes a submodule, we split the \textit{original} retiming problem of the module into an \textit{interior} and \textit{exterior}
        \begin{itemize}
            \item Exterior problem is constructed using the results of the interior problem
            \item Interior retimes subgraph for submodule
            \item Exterior retimes parents module, replace submodule with a \textit{contracted graph}
        \end{itemize}
    \end{itemize}

\begin{frame}[allowframebreaks]{Contracted Graph Construction}

  \begin{itemize}
    \item After retiming the contracted graph must have the same component delay, input delay, output delay, and component retiming difference as the original submodule
  \end{itemize}

  We give each node a popagation delay, then give each edge an initial weight and set constraints on $r$-values.

  \begin{itemize}
    \item Set $d(c_i)$ and $d(c_o)$ to 0, $d(d_i)$ to the input delay, $d(d_o)$ to the output delay, and $d(d_c)$ to the component delay
    \item Goals:
    \begin{itemize}
      \item We want the path through $d_c$ to be combinational, $w_r(c_i, d_c) = w_r(d_c, c_o) = 0$.
      \item A register between $d_i$ and $d_o$, $w_r(c_i, d_i)= w_r(d_o, c_o)=0$ and $w_r(d_i, d_o) \geq 1$.
    \end{itemize}
  \end{itemize}

  \framebreak

  We start by initializing $w(c_i, d_i) = w(d_o, c_o) = 0$.

  \begin{itemize}
    \item We add constraints requiring $r(c_i) = r(d_i)$ and $r(d_o) = r(c_o)$, maintaining zero weights
    \item To ensure $w_r(d_i, d_o) \geq 1$, choose $w(d_i, d_o) > r(c_i) - r(c_o)$, such as $r(c_i) - r(c_o) + 1$
  \end{itemize}

  We want the other path to end up being combinational.

  \begin{itemize}
    \item Start by arbitrarily setting $r(d_c) = r(c_i)$, then $w(c_i, d_c) = 0$.
    \item Finally, set $w(d_c, c_o) = r(c_i) - r(c_o)$
  \end{itemize}
